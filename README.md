# Аналитика интернет-магазина (PostgreSQL + pandas)

Итоговый проект курса «Python, pandas, PostgreSQL», НИУ ВШЭ.

## О проекте
Анализ 600 заказов интернет-магазина за 2025 год: выручка, сезонность,
категории, клиенты, отмены. Данные учебные.

## Что внутри
- `01_schema.sql` — схема БД (7 таблиц)
- `02_data.sql` - добавление данных
- `03_queries.sql` — 11 SQL-запросов (JOIN, CTE, оконные функции, представление)
- `analysis_final.ipynb` — анализ в pandas, графики, t-тест, выводы

## Ключевые результаты
- Средний чек: 20 609 ₽; повторно покупают 63,2% клиентов
- Электроника даёт 50,5% выручки; верхняя треть клиентов 71,4%
- Ноябрь и декабрь дают 27,8% годовой выручки
- Средний чек в будни и выходные не различается (t-тест Уэлча, p = 0,85)

## Стек
PostgreSQL, Python, pandas, matplotlib, seaborn, scipy, SQLAlchemy

## Как запустить
Создайте базу `shop`, выполните `01_schema.sql` и `02_data.sql`,
затем откройте `analysis_final.ipynb` и укажите свои параметры подключения.
